# Board Project
## Goal
Build a simple web discussion board from scratch. Anyone can read posts/comments; only authenticated users can create them.

## Core Features
- Login / logout
- Post list / detail / creation
- Comment list / creation

## Anonymous
Can read posts/comments. Cannot create posts/comments.

## Authenticated
Can read and create posts/comments and log out.

## Out of Scope
Registration, editing/deletion, likes, search, admin, attachments, social login.

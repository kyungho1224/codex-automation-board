이 폴더는 새 프로젝트 루트이며 애플리케이션 코드와 Git 저장소가 아직 없을 수 있다.

먼저 AGENTS.md와 AGENTS.md가 참조하는 docs 문서를 모두 읽어라.

AGENTS.md를 작업 절차의 source of truth로 사용하여:
1. Git 상태를 확인하고 필요하면 git init 및 main 브랜치 초기화를 수행한다.
2. remote가 없으면 현재 인증된 GitHub 도구로 안전하게 생성/연결 가능한지 확인한다. 불가능하면 BLOCKED로 기록하되 로컬 작업은 계속한다.
3. Bootstrap Phase로 실행 가능한 최소 프로젝트를 만든다.
4. 이후 PRD와 CURRENT_STATE를 기준으로 다음 feature를 스스로 선택한다.
5. 각 작업 단위마다 branch → 구현 → 테스트/typecheck/lint/build → CURRENT_STATE 업데이트 → commit → push → PR → CI 확인 → merge를 수행한다.
6. merge 후 최신 main에서 다음 feature를 선택해 반복한다.
7. QUESTION/BLOCKED/FEATURE_COMPLETE/SESSION_END는 NOTIFICATIONS.md 규칙을 따른다.
8. 질문이나 blocker가 생겨도 독립적으로 진행 가능한 작업이 있으면 멈추지 않는다.

문서에 없는 제품 정책을 임의로 확장하지 말고 일반적인 엔지니어링 판단은 스스로 결정해 진행한다.
